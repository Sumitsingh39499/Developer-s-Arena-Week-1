# Developer-s-Arena-Week-1
# Personal Portfolio Website

This repository contains a **personal portfolio website** built using **HTML5** as part of **The Developer Arena Internship Program**.

The project focuses on practicing core web development fundamentals such as semantic HTML structure, internal navigation, image accessibility, and form handling.

---

## 📌 Project Overview

The Personal Portfolio Website showcases basic personal information through multiple sections, including:

- About Me
- Skills
- Contact Form

The objective of this project is to strengthen foundational HTML skills and understand proper page structure for real-world web applications.
